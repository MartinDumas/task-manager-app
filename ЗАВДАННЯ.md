# ЗАВДАННЯ

## Застосунок

**Назва:** Task Manager API («Менеджер завдань»).  
**Опис:** локальний однокористувацький REST API для створення, перегляду, редагування, видалення та організації особистих завдань.  
**Цільові користувачі:** студент або користувач, що планує власні справи.

**Функціональні вимоги:**
- FR-01 — створення завдання.
- FR-02 — перегляд завдання.
- FR-03 — список завдань.
- FR-04 — редагування.
- FR-05 — керування статусом.
- FR-06 — видалення завдання.
- FR-07 — пошук.
- FR-08 — фільтрація й сортування.
- FR-09 — статистика.

**Технологічний стек:** Python 3.12+, FastAPI, Pydantic, SQLAlchemy 2.x, SQLite, pytest, Ruff, Git.  
**Повна специфікація:** [docs/app-requirements.md](docs/app-requirements.md).

## Обрана агентна IDE

JetBrains WebStorm + GitHub Copilot (Agent mode): MCP, виконання команд з підтвердженням, проєктні інструкції, skills (Preview) та custom agents. Для технічної реалізації hooks заплановано використовувати GitHub Copilot CLI у терміналі WebStorm, оскільки пряма підтримка hooks у JetBrains не гарантована. Основною IDE протягом курсу залишається WebStorm; механізми harness впроваджуються поступово.

## Мета harness

Прискорити типові задачі розробки Task Manager API, надавши AI-агенту актуальний контекст, структуровану базу знань через MCP та контрольовані процедури й обмеження. Агент пропонує зміни, а людина відповідає за архітектуру й рішення з підвищеним ризиком.

## Цільові задачі агента

1. Генерація каркасу модулів.
2. Генерація тестів.
3. Рев’ю коду.
4. Синхронізація документації.
5. Аналіз помилок тестування.

## Інфраструктурні рішення

- Два фізично окремі репозиторії: `task-manager-app` (застосунок + harness) і `task-manager-vault` (Obsidian knowledge layer).
- Vault доступний агенту лише через типізовані MCP-інструменти; direct filesystem access заборонено правилами й має обмежуватись середовищем.
- Guardrails: allow / warn or approval / block.
- Повна специфікація: [docs/harness-requirements.md](docs/harness-requirements.md).

**Статус ПР1:** документацію підготовлено; програмна реалізація, vault-нотатки, MCP, hooks і skills — предмет наступних практичних.
