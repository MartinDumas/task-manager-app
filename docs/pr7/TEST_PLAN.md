# ПР7 — план A/B-перевірки retrieval

**Умови:** 10 питань у `benchmark_10.json`; сталий vault (запис у нього заборонено на час досліду); один і той самий агент/модель/інструкція; доступ до джерел тільки через MCP.

## Послідовність

1. `python scripts/pr7_set_mode.py lexical`. У новій сесії Copilot для кожного Q01–Q10 попроси викликати `task-manager-vault.search_notes(query, limit=3)`, сформувати відповідь лише з отриманих джерел та навести шляхи нотаток.
2. Для важливих тверджень агент може викликати `get_note` за шляхом, поверненим MCP; прямий доступ до vault через файлові/термінальні tools заборонено GR-B03.
3. Запиши фактичну відповідь, джерела, оцінку 0/1/2 і скріншот у `results_actual.json` або звіт.
4. Побудуй індекс і ввімкни семантичний режим (`scripts/pr7_reindex.py ... --enable-semantic`), перезапусти MCP та створи нову сесію.
5. Повтори Q01–Q10 без змін формулювань, запиши повний результат.
6. `python scripts/pr7_compare.py docs/pr7/results_actual.json` та внеси фактичні бали/спостереження до звіту. У разі незавершених пунктів не приписуй нулі або бали довільно.

## Prompt для Copilot

> Використай лише MCP `task-manager-vault` (search_notes і, за потреби, get_note), щоб відповісти на запит нижче. Спочатку покажи виклик search_notes з limit=3 і реальні повернуті шляхи. Якщо підтвердження у vault недостатньо — прямо напиши про це. Не використовуй термінал або файлові інструменти для читання vault. Після retrieval сформуй стислу відповідь із посиланням на нотатку. Запит: [ОДНЕ ПИТАННЯ З benchmark_10.json].

## Підключення до навичок ПР5 та ролей ПР6

- `task-manager-unit-tests`: запитай про правила тестів з використанням того самого `search_notes`, переконайся, що skill застосовує знайдені вимоги, а не здогадки.
- `task-manager-adr`: попроси лише прочитати релевантні ADR через MCP; запис заборонений без окремого підтвердження.
- Planner: використай retrieval для обґрунтування плану; Coder: перевір використання handoff; Reviewer: звір джерела й укажи невизначеність. Не перетворюй запропонований ADR на прийнятий.

Ці кроки призначені для **фактичного** запуску в GitHub Copilot WebStorm. Штучні embedding-вектори локальних unit-тестів не доводять якість моделі sentence-transformers.
